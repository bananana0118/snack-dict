# SnackDictCriteriaAccordion

`SnackDictCriteriaAccordion`은 꽈자사전 등록 기준을 보여주는 전용 아코디언 컴포넌트다.
기본 아코디언 동작은 `SnackDictAccordion`을 사용하고, 등록 기준 콘텐츠와 태그 목록만 이 컴포넌트에서 관리한다.

## 사용 기준

- 꽈자사전 등록 기준 섹션을 표시할 때 사용한다.
- 범용 FAQ나 임의 콘텐츠를 받는 컴포넌트로 확장하지 않는다.
- 기본 상태는 펼침이며, 사용자는 접고 펼칠 수 있다.
- 카테고리와 맛 태그 색상은 `src/shared/styles/tokens.css`의 category/taste 토큰을 사용한다.

## 콘텐츠 기준

- 분류 기준과 맛 표기 종류 문구는 컴포넌트 내부 상수로 유지한다.
- 카테고리 태그는 `봉지`, `비스킷`, `파이`, `초콜릿`, `젤리`, `캔디&껌` 순서로 표시한다.
- 맛 태그는 `달콤`, `상큼`, `짭짤`, `매콤`, `쌉싸름`, `느끼` 순서로 표시한다.
